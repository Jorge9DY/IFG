# Datos

JSON con el contenido y el balance del juego, separados del código para ajustarlos sin tocar la lógica:

- `balance.json`: calendario, misiones, héroes, sueldos, valor, novatos, reclutas, instalaciones, ranking, premios, gremio inicial y comportamiento de los rivales.
- `gremios.json`: los gremios rivales (biblia, sección 14) y los títulos de las misiones.
- `nombres.json`: nombres y apellidos de los héroes.

Las cifras son ilustrativas o provisionales hasta que se equilibren (ver `docs/preguntas.md` y `docs/informe-balance.md`).
