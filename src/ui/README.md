# Interfaz

Paneles de gestión en HTML/CSS/TypeScript, superpuestos a la sede 3D. Solo leen el estado del motor y le envían acciones; no contienen reglas del juego.

Pantallas del prototipo (sección 15 del diseño): Sede, Mercado, Puja, Plantilla, Tablón de misiones, Formación, Informe y Clasificación.
