Pantalla principal (biblia, sección 3): oro, Finalizar día, Gestionar gremio (plantilla, reclutar, instalaciones y ranking), Lanzar misiones y Mercado de héroes. Paneles secundarios: Prueba de los Novatos, resumen del día y ranking de la semana.
