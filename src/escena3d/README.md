# Escena 3D

Sede del gremio en Three.js: escena, protagonista, cámara y puntos de interacción. Solo lee el estado del motor y avisa a la interfaz cuando el jugador interactúa; no contiene reglas del juego.

- `sede.ts`: versión con formas simples (cajas y cápsulas). Se sustituirán por modelos `.glb` de `public/modelos/` en la fase 4.
